# 이동윤 | AI Engineer

데이터와 모델을 이해하고, AI 기능을 서비스로 연결하는 개발자를 지향합니다.  
머신러닝 모델링, 웹서비스 배포, AI·RAG 및 다중 에이전트 프로젝트를 경험하며 구현 과정의 선택과 검증을 기록하고 있습니다.

## Projects

### [WaterBridge](https://github.com/ldy-99/SKN29-FINAL-4TEAM)
멀티 에이전트 기반으로 정수기 구독 고객의 문의부터 AI 안내, 상담, 해결 확인까지 연결하는 고객케어 플랫폼입니다.

- **담당:** 다중 에이전트 설계 및 AI·RAG 구현
- **주요 내용:** 문진 분석, 공식 문서 검색, 답변 생성, 안전 검증의 역할 분리와 에이전트 간 처리 흐름 설계
- **진행:** 팀 프로젝트 완료 · 개인 사후진단 정리 중

### [A-FIT](https://github.com/ldy-99/SKN29-4TH-3Team)
사용자 조건과 모집공고를 바탕으로 청약 가능성을 진단하는 AI 웹서비스입니다. 3차 프로젝트를 발전시켜 4차 프로젝트로 확장했습니다.

- **담당:** 배포·백엔드 — Docker 이미지 빌드 및 배포, AWS EC2 환경 구성, Nginx·Gunicorn 설정
- **관련 저장소:** [3차](https://github.com/ldy-99/SKN29-3rd-3team) · [4차](https://github.com/ldy-99/SKN29-4TH-3Team)

### [TrendIt](https://github.com/ldy-99/SKN29-2nd-1Team)
YouTube 트렌딩 데이터를 기반으로 콘텐츠 성과와 지속 가능성을 예측하는 분석 플랫폼입니다.

- **담당:** 데이터베이스 설계·머신러닝 모델링
- **주요 내용:** 트렌딩 진입 시점의 정보를 활용한 예측과 모델 성능 평가
